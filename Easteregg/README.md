## 📖 序言

FluentGit 是一个严肃的、现代的、基于 WinUI 3 / Windows App SDK 的 Git 图形客户端。
它使用 C# / .NET 10 编写，追求 Fluent Design 的清爽与克制。

而这份文件夹，是它不克制的部分。

本目录下的每一份文档，都描述了 FluentGit 代码库中真实存在（或计划存在）的一段“赛博迷信”。
它们不影响任何功能、编译或运行时行为——除非你删掉它们。
删掉它们，一切照旧。但你晚上会睡不着。

> ⚠️ 声明：本目录全部内容属于开发者自嘲式幽默与工程文化玩梗，不代表任何宗教信仰立场。
> 我们对一切宗教与文化保持尊重。佛祖在这里，是作为一个代码守护符号存在的。

## 🔢 功德值系统

FluentGit 内部维护一个纯虚构的功德值（Merit）体系。

- 功德值不可兑换任何实物、虚拟物品、许可证或折扣。
- 功德值不可转让、不可继承、不可挂失。
- 功德值唯一的作用是让你在深夜 `git push --force` 之前，犹豫 0.5 秒。

| 行为 | 功德 |
|---|---:|
| 电子佛祖常驻 `MainWindow.xaml.cs` | +100 |
| Release 前上香 | +10 |
| 写了一个有意义的 commit message | +5 |
| 补了一个单元测试 | +8 |
| 修了一个自己三年前留下的 Bug | +20 |
| 写了一个 `// TODO: 以后再改` | −5 |
| 删掉 `Easteregg/` 文件夹 | −∞ |

## 🚀 如何使用

1. 阅读：随手翻翻，图一乐。
2. 执行：按文档中的仪式操作，比如在提交前上香。
3. 贡献：想加新彩蛋？见下一节。
4. 传播：把 `Buddha.md` 里的 ASCII 圣像复制到你自己的项目里。佛祖不分项目，功德照算。
